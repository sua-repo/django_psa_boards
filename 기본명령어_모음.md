1. 파이썬 실행
    python manage.py runserver

2. DB DDL 파일 만들기
    python manage.py makemigrations
    # pybo\migrations\0001_initial.py 파일 생성
    
3. DDL 파일 실행
    python manage.py migrate

4. 장고 관리자 계정 생성
    python manage.py createsuperuser
    # http://127.0.0.1:8000/admin

5. 소스코드를 다이렉트로 실행
    python manage.py shell
